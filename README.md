# 🥟 Russian Snacks: Pelmeni Bowl (128x)

A high-quality, detailed resource pack for Minecraft that replaces the standard vanilla Mushroom Stew item with a legendary bowl of pelmeni. This edition features the most iconic and beloved comfort food: Pelmeni (Meat Dumplings).

---

## ⚙️ Technical Info & Compatibility

This resource pack officially supports Minecraft versions from **1.20.1 up to the latest**.

* *If you encounter any minor visual bugs or glitches, simply reload your textures in-game by pressing **F3 + T**.*
